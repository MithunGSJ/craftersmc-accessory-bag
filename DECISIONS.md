# Architectural Decisions

| ID | Decision | Reason |
| :--- | :--- | :--- |
| DEC-001 | Use Vite + React + TypeScript in strict mode | Provides instantaneous HMR, robust static typing, and lightweight runtime without framework bloat. |
| DEC-002 | Use pure Vanilla CSS with design token variables (no Tailwind) | Complies with project guidelines, enables pixel-perfect custom Minecraft/SkyBlock glassmorphism aesthetic. |
| DEC-003 | Separate pure logic from UI rendering | Ensures 100% testability with Vitest unit tests for NBT decoding, MP calculation, and upgrade resolution. |
| DEC-004 | Support both live API lookup, Base64 NBT input, and bundled offline demo profiles | Ensures full functionality even if user does not supply an API key or has rate limit constraints. |
| DEC-005 | Synthesize audio using Web Audio API | Zero external audio asset dependencies, instantaneous playback, zero latency, toggleable for user convenience. |
| DEC-006 | Group accessories into Upgrade Families | Prevents false positives where possessing a higher tier (e.g., Zombie Artifact) would flag lower tiers (Zombie Ring) as missing. |
| DEC-007 | Embed mandatory CraftersMC and Minecraft trademark disclaimers | Ensures full compliance with section 1 of the CraftersMC API Usage Policy. |
| DEC-008 | Scope accessory catalog strictly to active CraftersMC SkyBlock items | Strips non-existent Hypixel Dungeons / Catacombs / Enderman Slayer items (Wither Relic/Artifact, Auto-Recombobulator, Hegemony) to mirror true CraftersMC game state. |
| DEC-009 | Sync with official CraftersMC Wiki table and incorporate live API key | Added all 85 authentic obtainable accessories across 46 upgrade families, verified live API key for DarkKing0098994, and supported native CraftersMC NBT inventory format. |
| DEC-010 | Replace legacy Hypixel coin estimations with authentic CraftersMC Wiki obtaining requirements & progression milestones | CraftersMC accessories are governed by Collections, Quests, Slayers, Drops, and NPC Shop prices. |
| DEC-011 | Download and bundle authentic CraftersMC Wiki pixel-art sprites for all accessories | Replaced generic emojis with official high-resolution wiki item sprites rendered crisply with `image-rendering: pixelated;` and emoji fallback. |
| DEC-012 | Set Golden Feather Boots as Tier 4 upgrade of Feather Artifact in feather family | Aligns with user specification; computes upgrade MP difference and combines Feather Artifact cost with 64x Enchanted Feathers. |
| DEC-013 | Integrate live CraftersMC Bazaar material prices & active Auction House endpoints | Computes live craft costs from Bazaar weekly average prices multiplied by material counts, alongside direct active auction min/max/avg ranges. |
| DEC-014 | Prioritize active BIN listings with outlier trimming & dual-tier material comparison | Prevents unbid troll normal auctions from skewing averages, and audits exact in-game recipe grids (e.g. 9x Enchanted Lapis Blocks vs 1,440x Enchanted Lapis Lazuli). |
| DEC-015 | Strictly hide superseded lower-tier accessories when a higher tier in that family is owned | Eliminates obsolete zero-MP cards (e.g. Personal Deletor 4000/5000/6000 when 7000 is owned) to keep the catalog clean. |
| DEC-016 | Place Dayfreezer and Nightfreezer into shared day_night_freezer family with non-stacking MP | Enforces that only one of Dayfreezer or Nightfreezer grants active +16 MP in the bag, matching game mechanics. |
| DEC-017 | Format exact NPC shop prices without 'Est:' or '~' prefixes and preserve Gems currency | Ensures NPC items display exact vendor price (e.g. Sky's Badge: 21.5M, Zoe: 945 Gems) and prevents unit regex matching Gems as Billions. |
| DEC-018 | Create typed helper factory `r()` for `accessoryRecipes.ts` | Eliminates 182 lines of repetitive object keys while preserving TypeScript type safety and structure. |
| DEC-019 | Memoize pricing engine evaluation and precompute bag statistics | Prevents redundant craft-tree recursive re-evaluations during UI re-renders and eliminates repeated family map iterations. |
| DEC-020 | Include UPGRADABLE_NEXT accessories in Missing tab with dual tags | Enables players to view all unowned higher-tier accessories in the Missing tab while clearly labeling upgrade availability. |
| DEC-021 | Implement authentic Minecraft double-chest inventory interface with hover tooltips | Recreates the authentic in-game Accessory Bag GUI with 9x5 beveled slots, pixel-art sprites, floating item tooltips, and click modal inspection. |
| DEC-022 | Correct accessory hierarchy (Fire Talisman standalone, Fire Extinguisher -> Fire Devourer, Frostclaw Relic -> Red Claw Artifact, Reaper Orb standalone) and verify crafting recipes | Aligns accessory families and recipes strictly with official CraftersMC Wiki (craftersmc.wiki.gg). |
| DEC-023 | Update Special rarity Magical Power to 5 MP | Accurately matches official CraftersMC Thaumaturgy Magical Power table (<https://craftersmc.wiki.gg/wiki/Thaumaturgy#Magical_Power>). |
| DEC-024 | Display owned bag accessories strictly in NBT slot order in chest GUI, and render Missing & Upgradable accessories in Card Grid at bottom | Respects in-game line-up order in chest view while keeping missing/upgradable progression accessible in full card layout below. |
| DEC-025 | Verify 100% of non-Special accessory recipes and market pricing from CraftersMC Wiki | Corrected 25 crafting formulas across collections, slayers, compactors/deletors, and spooky events, and validated market pricing without outliers. |
| DEC-026 | Retain solely Fresh Profile and Lookup Player in profile selector bar, and display 'No offers were made in auction house' when auction history is unavailable | Per user direction, removes pre-bundled profile shortcuts to streamline focus on player lookup and empty state audit, and replaces 'Unobtainable' with accurate auction history messaging. |
| DEC-027 | Suppress auction house pricing for all accessories purchasable from NPCs with coins | Per user direction, accessories bought from NPCs with coins have a fixed, guaranteed vendor price (e.g. Mine Affinity 2.5K, Sky's Badge 21.5M, Scavenger 10K, Skeleton 500) and do not need auction house price displays on cards or in modals. |
| DEC-028 | Value base NPC accessories in upgrade recipes at their authentic NPC vendor cost | When an accessory recipe upgrades from a base accessory that has an NPC shop cost (e.g. Zombie Talisman sold for 500 coins by Julia/Adventurer), the recipe calculator uses its exact NPC purchase cost (500 coins) rather than fallback auction prices. |
| DEC-029 | Isolate CraftersMC API Key strictly to server-side proxy | Per user direction, removes all client-side API key references, state, input fields, and request headers. The key is managed via server environment variables (.env / Vite server proxy) and injected server-side during outbound requests to api.craftersmc.net, ensuring the client bundle and network traffic never expose the key. |
| DEC-030 | Remove Direct Base64 NBT Paste tab to streamline Player Lookup | Per user direction, removes raw NBT paste textarea and alias inputs, focusing the modal and header button solely on direct player lookup via the live CraftersMC API. |
| DEC-031 | Initialize Player Lookup input empty on modal open | Per user direction, the input field in Player Lookup modal starts empty rather than pre-filling DarkKing0098994, using an example placeholder instead, while preserving demo testing if left empty on Test Player click. |
| DEC-032 | Size Minecraft chest container and slots grid to fit-content | Per user direction, removes excessive blank space to the right of column 9 by constraining container and grid to fit-content (440px inner / 472px outer) and streamlining footer pagination labels. |
| DEC-033 | Sort Card Grid View by authentic accessory bag slot order | Per user direction, sorts all accessories in Card Grid View by their exact in-game bag slot index (`ownedItem.slot`), displaying owned accessories in exact slot order followed by missing items, and showing slot badges. |
| DEC-034 | Aggregate live auction data into /api/pricing/live background middleware | Provides dynamic real-time auction market stats with outlier trimming to client pricing engine with 5-minute memory cache. |
| DEC-035 | Decode dynamic Mojang skull textures and synthesize uncataloged accessory definitions | Enables zero-day accessories to render exact head textures via pixelated 8x8 face crop and automatically assigns active MP based on item lore rarity without crashing. |
| DEC-036 | Implement automated MediaWiki scraper engine with sprite sync | Scrapes craftersmc.wiki.gg/api.php for authentic accessories, decodes HTML entities, and auto-downloads official PNG sprites with retry backoff to /public/icons/accessories/. |
| DEC-037 | Implement automated GitHub Actions daily sync and validation workflow | Runs daily scheduled cron at midnight UTC to sync MediaWiki accessories, execute Vitest tests, run production build, and automatically commit sprite assets. |
