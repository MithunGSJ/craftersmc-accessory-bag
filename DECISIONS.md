# Architecture & Design Decisions

- **Bazaar Item ID Aliasing for Envoy's Horn (`envoy_horns`)**: CraftersMC API names the Bazaar product `envoy_horns` (plural), whereas wiki recipes referred to `envoys_horn`. Added bi-directional alias mapping in `pricingEngine.ts` and `syncPricing.ts` so both names seamlessly resolve to live Bazaar data.
- **Red Claw Egg Baseline Retention & Fallback Logging**: CraftersMC REST API (`/v1/resources/skyblock/bazaar/items`) maintains an exact whitelist of 285 allowed Bazaar items which currently excludes `red_claw_egg`. Retained baseline price (8,500,000 coins) and updated sync logging to identify retained fallback baseline instead of misleading `UNTRADED` warnings.
- **Browser Navigation vs API Key**: Direct browser navigation to `api.craftersmc.net` lacks the required `X-API-Key` HTTP header. Documented browser testing via local Vite / Vercel proxy (`/api/v1/...`) which transparently attaches the required header.
- **Dayfreezer & Nightfreezer Mutual Resolution**: Dayfreezer and Nightfreezer belong to the same family (`day_night_freezer`) and share non-stacking MP; owning either one resolves the family, suppressing the unowned one from being shown or counted as missing.
- **Fused Remnants Fixed NPC Valuation (6.4M)**: Fused Remnants are crafted from 32x Remnant of the Eye, purchasable from the End NPC at 200,000 coins each (6,400,000 coins total); bypassed Bazaar API checks in automated sync and live dev plugins, establishing 6.4M as authoritative material cost with subMaterial breakdown for Draconic accessories.
- **Fluid 9-Column Fractional Responsive Inventory Grid for Mobile**: Replaced hardcoded 34px fixed columns on mobile with fluid `repeat(9, minmax(0, 1fr))` and `aspect-ratio: 1 / 1` slots to guarantee exact bounding within mobile screens down to 320px without horizontal overflow.
- **160x160 High-Resolution Sprite Assets & Cross-Browser Pixelated Rendering**: Upgraded accessory icon assets to 160x160 PNGs sourced directly from CraftersMC wiki and configured `-webkit-optimize-contrast`, `crisp-edges`, and `pixelated` rendering with GPU subpixel alignment for crystal-clear visuals on mobile retina/OLED displays.
- **Strict SSRF Mitigation in API Proxy**: Enforced exact origin matching against `TARGET_API_BASE` and sanitized URL path prefixes to prevent hostname injection and API key exfiltration.
- **NBT Prototype Pollution Defense**: Initialized NBT compound dictionaries with `Object.create(null)` and filtered out `__proto__`, `constructor`, and `prototype` keys.
- **Single-Flight Auction & Bazaar Rate Throttling**: Deduplicated concurrent live pricing queries into a single in-flight promise and paced external API requests by 200ms to stay within the 40 req/min quota.
- **Accurate Upgrade Recommendation Delta**: Fixed Magical Power calculations in recommendation cards to compute net MP gain between current owned tier and candidate tier instead of looking ahead to higher tiers.
- **Format 2 NBT Slot Integrity**: Preserved in-game inventory slot byte positions from NBT compounds instead of indexing sequentially.
- **Seal of the Seas and Seal of the Oceans Mutual Exclusivity**: Modeled `SEAL_OF_THE_SEAS` and `SEAL_OF_THE_OCEANS` as independent tier 1 families (`seal_of_the_seas`, `seal_of_the_oceans`) rather than a 2-tier chain, and added mutual exclusivity logic in `accessoryMatcher` so owning one marks the other as owned/satisfied with 0 additional MP.
- **Accessory Category Typing for Piggy Bank**: Classified Piggy Bank as `Misc` rather than `Combat` or an unsupported `Automation` category, keeping category types strictly typed to the `AccessoryCategory` union.
- **Lore Word Boundary & Substring Protection in Wiki Brain and Parser**: Replaced loose substring checks with regex word boundaries `\b(COMMON|UNCOMMON|RARE|EPIC|LEGENDARY|MYTHIC|SPECIAL|VERY SPECIAL)\b` to prevent false positive keyword matches inside item lore descriptions.
- **Strict Bounds Checking in NBT Reader**: Added `ensureBytes()` buffer boundary guards across all primitive read operations (`readByte`, `readInt`, `readFloat`, etc.) to prevent unhandled `RangeError` on truncated or corrupted player data.
- **Pricing Engine Safety & Sanitization**: Guarded `formatCoins` with `Number.isFinite`, safe integer boundaries, and clamped negative coins to 0 to prevent displaying `-0k` or `NaN`.
- **Vercel Rewrite Path Parameter Forwarding**: Updated `vercel.json` to rewrite `/api/v1/:path*` to `/api/proxy?path=:path*` and updated `api/proxy.ts` to inspect `query.path`, preserving downstream endpoint subpaths while forwarding incoming authorization headers.
